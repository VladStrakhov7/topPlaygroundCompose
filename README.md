# Футбольные матчи

Android приложение для просмотра результатов футбольных матчей из OpenLigaDB API с возможностью сохранения избранных матчей.

## Описание

Приложение получает последние матчи из OpenLigaDB API и отображает их в виде списка. Пользователи могут:
- Просматривать список последних матчей
- Открывать детальную информацию о матче
- Сохранять матчи в избранное
- Просматривать сохранённые матчи

## Технологии

- **Kotlin** - основной язык разработки
- **Jetpack Compose** - современный UI фреймворк
- **MVVM** - архитектурный паттерн
- **Clean Architecture** - разделение на слои (data, domain, presentation)
- **Hilt** - dependency injection
- **Retrofit** - для работы с REST API
- **Room** - локальная база данных
- **Coroutines & Flow** - асинхронное программирование
- **Jetpack Navigation** - навигация между экранами

## Архитектура

Проект следует принципам чистой архитектуры и разделён на три основных слоя:

### Data Layer
- `api` - работа с OpenLigaDB API (Retrofit)
- `local` - локальное хранилище (Room Database)
- `repository` - репозитории для управления данными

### Domain Layer
- `model` - доменные модели
- `usecase` - бизнес-логика (Use Cases)

### Presentation Layer
- `screen` - экраны приложения (Compose UI)
- `component` - переиспользуемые UI компоненты
- `viewmodel` - ViewModels для управления состоянием
- `navigation` - настройка навигации

## Функциональность

### Главный экран
- Отображение списка последних матчей из OpenLigaDB
- Кнопка для перехода к сохранённым матчам
- Клик по карточке матча открывает детальную информацию

### Детальный экран матча
- Подробная информация о матче
- Кнопка для сохранения/удаления из избранного
- Навигация назад

### Экран сохранённых матчей
- Список всех сохранённых матчей
- Возможность открыть детали любого сохранённого матча
- Навигация назад

## Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
```

2. Откройте проект в Android Studio

3. Дождитесь синхронизации Gradle

4. Запустите приложение на эмуляторе или физическом устройстве

## Использование

1. При запуске приложение автоматически загружает последние матчи из API
2. Для просмотра деталей матча нажмите на карточку
3. На детальном экране нажмите кнопку "Сохранить матч" для добавления в избранное
4. Для просмотра сохранённых матчей нажмите на иконку избранного в верхней панели главного экрана

## API

Приложение использует [OpenLigaDB API](https://www.openligadb.de/):
- Endpoint: `https://api.openligadb.de/getmatchdata/bl1`
- Получает матчи из Бундеслиги (1. Fußball-Bundesliga)

## База данных

Приложение использует Room Database для локального хранения:
- Таблица `matches` - хранит информацию о матчах
- Поле `isFavorite` - флаг избранного матча
- Версия базы данных: 2
